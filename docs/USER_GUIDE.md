# MiyuManager 用户指南

## 首次启动

1. 选择包含游戏主程序的目录。
2. 等待扫描，确认每部游戏的主程序和显示名称。
3. 按需启用 VNDB、Bangumi、Kungal、Hikarinagi 或 Steam。来源可以稍后设置。
4. 完成后进入游戏库。数据默认保存在 `%APPDATA%\MiyuManager`。

## 添加与启动游戏

在游戏库点击“添加目录”，或使用“扫描 Steam 库”。确认后作品会写入本地库。

作品详情页可以编辑标题、原题、简介、标签、状态、评分和评价。启动配置由“游戏目录 + 可执行文件名”组成；Locale Emulator 与 Magpie 可在设置中分别配置，在作品详情中独立启用。管理器只跟踪由自己启动的游戏会话，不读取存档、章节、路线或游戏内进度。

## 收藏、搜索与统计

- `Ctrl+K` 搜索作品、别名、标签和收藏集。
- 收藏集是手动分组；删除收藏集不会删除作品。
- 统计来自实际启动会话；详情页可以补录、修正或删除记录。

## 数据与备份

“设置 → 数据与关于”可以：

- 打开数据目录、备份目录和日志目录。
- 使用 SQLite 在线快照备份数据库。
- 从已验证的备份恢复；恢复前会自动留下安全快照，应用随后重启。
- 查看数据库完整性、迁移数量和更新检查状态。

备份只保存数据库，不包含游戏文件和封面缓存。

## 自动更新

应用启动后每 24 小时检查一次 GitHub Release。发现更新时，右下角会出现提示；“设置 → 数据与关于”可以查看版本说明、检查更新、下载并安装。

更新包会先通过 Tauri 更新签名校验，再下载安装。Windows 安装阶段会显示系统进度窗口，完成后应用自动重启。自动检查可以关闭，手动检查仍然可用。

安装器当前没有 Authenticode 代码签名，首次运行时可能出现 SmartScreen 提示；这与自动更新签名是两套独立机制。

## 电视大屏

在设置中选择显示器并打开大屏。手柄 A 确认、B 返回、Y 打开游戏菜单、Start 打开控制菜单，LB/RB 切换分类，LT/RT 翻页，SELECT 或键盘 F、/ 打开搜索键盘。B/Escape 只逐层返回，退出大屏在控制菜单中。
