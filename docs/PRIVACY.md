# MiyuManager 隐私说明

MiyuManager 是本地优先应用。游戏库、扫描目录、启动配置、游玩会话、用户状态、评分、评价、收藏集和应用设置保存在用户本机的数据目录中。

应用默认不发送遥测、不创建分析账号、不上传游戏路径或游玩时长。元数据搜索会把查询标题发送到用户启用的来源服务；OAuth 登录会把授权请求发送到对应平台。网络代理和更新清单地址由用户配置。

诊断日志写在本地 `logs/`，包含时间、版本、事件、错误信息和崩溃堆栈。应用不会主动上传日志。请在上传日志给他人排查前检查其中的本地路径和个人内容。

卸载应用不会自动删除 `%APPDATA%\MiyuManager`；用户可以在备份后手动清理数据目录。
