# MiyuManager 0.1.0 发布候选说明

这一版完成 C8 产品壳与 C9 发布硬化，包含本地游戏库、目录与 Steam 导入、作品详情、封面缓存、启动配置、Locale Emulator/Magpie 包装器、多源元数据、游玩会话、统计、收藏集、全局搜索、首次启动、电视大屏和搜索键盘。

C9 新增：

- SQLite 在线备份、恢复前安全快照、迁移前快照和完整性检查。
- 本地 JSONL 诊断日志、崩溃记录和前端错误边界。
- CSP、导航白名单和主窗口/大屏分窗口 capability。
- MSI/NSIS 构建配置、发布检查脚本、发布清单与 SHA-256 校验生成流程。

本轮验证：`pnpm release:check` 通过，前端 11 个测试文件、53 项通过，Rust 82 项通过、13 项按环境/人工条件忽略；数据库备份/恢复、安全导航与诊断测试通过；10,000 部作品与 5,000 条封面记录的查询基准为首屏 87ms、搜索 63ms、末页 92ms。Release EXE 已生成并通过 8 秒启动冒烟，SHA-256 为 `d2b5989c3f503eb818c6bc220ba3acc9647e4383e20381a1c90108fda00edf72`。

已知限制：当前只生成 `executable-only` Release EXE，MSI/NSIS 因构建环境无法联网下载 WiX/NSIS 尚未生成；包未签名。G6 的正式版本号、便携版、证书和自动更新策略仍待确认。物理手柄、多显示器、干净 Windows 10/11 安装与卸载尚未在当前机器完成实测。
