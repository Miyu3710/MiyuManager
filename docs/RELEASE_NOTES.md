# MiyuManager 0.2.1

修复部分游戏从 MiyuManager 启动后闪退、且没有记入游玩时长的问题。

## 修复

- 游戏由前置启动器、转交进程或同目录下的另一个可执行文件接手时，MiyuManager 会继续在整个进程树和游戏目录中识别真正的主程序。
- 不再因为 60 秒内没有识别到登记的 exe 而结束游戏进程树；直接双击正常、从启动器启动却“闪退”的问题由此消除。
- 游玩会话改为在进程创建时立即建立；后续找到游戏主程序时更新 PID 和 exe 路径。启动后很快退出的会话也会留下记录和有效时长。
- 会话从启动器进程交接后仍能继续计时；“停止游戏”继续支持结束作业对象外的实际进程。

## 安装

- 支持 Windows 10 22H2 / Windows 11 x64。
- MSI 与 NSIS 安装包暂未使用 Authenticode 代码签名，首次下载可能出现 SmartScreen 提示。
- 自动更新载荷由 Tauri 更新密钥独立签名，安装前会校验签名。
