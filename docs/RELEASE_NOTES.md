# MiyuManager 0.2.2

修复 0.2.1 在部分已有数据库上无法启动的问题，并保留 0.2.1 的启动交接修复。

## 重要修复

- 0.2.1 的 CI 构建在 Windows 检出迁移 SQL 时把 LF 转成了 CRLF，导致 SQLx 迁移校验值与已有数据库不一致，应用启动即退出。
- 迁移文件现已固定为 LF；CI 增加了换行回归测试，后续版本不会再因检出行尾变化破坏已有数据库。
- 0.2.1 的启动器交接、短会话记录和不结束游戏进程树的修复继续保留。

## 升级说明

- 已安装 0.2.1 的用户无法从应用内更新，请手动下载本版本的 NSIS 或 MSI 安装包覆盖安装；现有数据库会保留。
- 0.2.0 用户可以正常通过设置页自动更新到 0.2.2。

## 安装

- 支持 Windows 10 22H2 / Windows 11 x64。
- MSI 与 NSIS 安装包暂未使用 Authenticode 代码签名，首次下载可能出现 SmartScreen 提示。
- 自动更新载荷由 Tauri 更新密钥独立签名，安装前会校验签名。
