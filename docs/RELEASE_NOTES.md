# MiyuManager 0.3.0

新增游戏内截图、截图图库与截图设置。

## 新功能

- 游戏运行时注册全局截图快捷键，默认 `Ctrl+Shift+F12`：截取前台游戏窗口客户区，按原分辨率保存无损 PNG；游戏退出后自动注销，可在“设置 → 截图”重新录制，修改立即生效。
- 截图默认保存到 `Pictures\MiyuManager\Screenshots\<作品标题>`，作品文件夹内只保留原图；缩略图与归属索引存放在应用数据目录的 `screenshots-cache`。旧版 `_thumbs`/`_miyu.json` 会在读取或下次截图时自动迁移清理。
- 截图成功后在游戏画面右下角显示无投影的半透明提示，不抢占焦点，约 2.4 秒后自动消失。
- 新增“图库”页与作品详情“截图”标签：支持按作品筛选、缩略图网格、全屏预览、上一张/下一张、在文件夹中显示和打开截图目录。

## 已知限制

- 截图使用 Windows GDI 采集 8 位 RGB 画面；HDR/10 位色深与部分独占全屏游戏可能无法正确截取，建议使用窗口或无边框窗口模式。
- 截图目录可以随时更改，已有文件不会被移动或删除；缩略图缓存位于 `%APPDATA%\MiyuManager\screenshots-cache`，删除后应用会按需重建。
- 本次更新不包含数据库迁移，已有作品、游玩记录、收藏与设置会保留。

## 安装

- 支持 Windows 10 22H2 / Windows 11 x64。
- MSI 与 NSIS 安装包暂未使用 Authenticode 代码签名，首次下载可能出现 SmartScreen 提示。
- 自动更新载荷由 Tauri 更新密钥独立签名，安装前会校验签名。
